# Chzzk Ambient Mode

치지직(chzzk.naver.com)에 유튜브 앰비언트 모드 같은 글로우를 입히는 크롬 확장 프로그램입니다.
[youtube-ambilight](https://github.com/WesselKroos/youtube-ambilight)의 원리(영상 프레임을 작은 캔버스에 그려 플레이어 뒤에서 크게 흐리게 표시)를 단순하게 옮겼습니다.

## 기능
- 영상 색이 플레이어 주변과 페이지 전체(헤더, 사이드바, 채팅)로 퍼지는 글로우
- 플레이어 하단 녹화 버튼 왼쪽의 ☀ 설정 버튼: 켜기, 크기, 흐림, 밝기, 채도, 패널 불투명도
- 전체화면에서는 화면 위아래 여백에 글로우 표시
- 확장 아이콘 팝업: 같은 설정 + 글로우가 안 보일 때 원인 진단

## 설치
1. [Releases](../../releases)에서 `chzzk-ambient-mode.zip`을 받아 압축을 풉니다. (또는 이 저장소를 clone)
2. 크롬에서 `chrome://extensions`로 이동해 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
4. 치지직 탭을 새로고침합니다.
